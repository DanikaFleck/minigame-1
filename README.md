# Minigame 1
## Devlog

Danika Fleck, she/her

The way that a Scene, GameObject, and Component relate to each other is similar to a sock puppet show. The Scene is the stage, the setting. The GameObject is a blank, uninhabited sock. The Components are everything that make up the features of the sock puppet: the hand that controls it, the eyes and mouth that make the puppet distinct, the voice and mannerisms it has.
